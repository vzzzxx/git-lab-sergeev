Изучить основы работы с системой контроля версий Git, научиться создавать репозитории, фиксировать изменения, работать с ветками и синхронизировать локальный репозиторий с GitHub.

 ## 2. Ход выполнения работы
 Задание 1-2: Настроены глобальные параметры `user.name` и `user.email`. Создана рабочая папка и инициализирован локальный репозиторий.
 Задание 3: Созданы базовые файлы проекта (`README.md`, `index.html`, `style.css`, `script.js`).
 Задание 4: Создана ветка `feature`, внесены изменения в стили, выполнено слияние с веткой `master` и удаление ветки.
 Задание 5-6: Выполнена отправка данных на удаленный репозиторий GitHub и синхронизация изменений (`git pull`).
